# AstraInvest AI Downloads

This public repository hosts published binary releases for AstraInvest AI. Application source code is maintained in the private [`Iketips/astrainvest-ai`](https://github.com/Iketips/astrainvest-ai) repository.

## Windows installer

Download the latest Windows installer from the [Releases](https://github.com/Iketips/astrainvest-ai-downloads/releases) page.

The application is paper-trading only. Live trading is disabled. Installers are unsigned and Windows may show an unverified-publisher warning.
